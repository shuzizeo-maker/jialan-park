# 🎡 嘉蘭遊樂場（Jialan Park）

結合國小國語、數學、英語、自然、社會的 3D 闖關遊樂園（三～六年級）。純靜態網頁，免建置，可直接部署到 Vercel。

- **五大園區**：📚 文字森林（國語）、🪐 數字星球（數學）、⚓ ABC 港灣（英語）、🌿 探險叢林（自然）、🏰 世界城堡（社會）
- **11 座設施**：點設施或名牌即可闖關（每回合 5 題，答對 4 題得 ⭐；集滿園區星星得徽章；五枚徽章全到手施放煙火秀）
- **背景音樂**：`assets/bgm.mp3`（按「開啟音樂」循環播放；闖關時自動調小聲；音檔失敗時改用內建合成音樂）
- **改題目**：編輯 `questions.js`；**改設施名稱/位置**：編輯 `lands.js`
- **本機預覽**：在資料夾中執行 `python -m http.server 8000`，再打開 <http://localhost:8000>
- **部署**：請看 [`部署教學.md`](./部署教學.md)
- 網址加 `?quality=high` 可關閉自動降畫質（電腦展示用）
